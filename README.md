# Project-Based Learning

This repository contains hands-on exercises and supporting materials for the Project-Based Learning course.

## Course Approach

The course explores how data, AI, and digital technologies can be used to:

- understand real-world business problems,
- collect and evaluate evidence,
- support business decisions,
- identify new business opportunities, and
- develop project ideas.
