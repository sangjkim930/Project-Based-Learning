# Week 3: Gemini API Practice

## AI in Business Operations and Decision-Making

### Learning Objective

In this exercise, you will use the Gemini API and Google Colab to analyze multiple PDF documents and retrieve evidence from them.

You will practice the following workflow:

**Upload → Prompt → Run → Verify → Modify**

---

## Documents

Use the following three documents provided through the LMS:

1. `01_Nepal_Economy_2024_25_NRB.pdf`
2. `02_Nepal_Development_Strategy_2025_29_ADB.pdf`
3. `03_Nepal_Development_Update_2026_WorldBank.pdf`

Do not rename the files.

---

## Before You Start

You need a Gemini API key.

Save your API key in **Google Colab Secrets** using the following name:

`GEMINI_API_KEY`

Do not write your API key directly in your notebook or source code.

---

## Exercise

1. Open Google Colab.
2. Copy the provided code into separate Colab cells.
3. Upload the three PDF documents.
4. Run the Gemini API query.
5. Review the generated answer.
6. Check at least one important claim against the original PDF.
7. Change the research question and run the code again.

---

## Example Research Question

> What are the three most important economic and development challenges facing Nepal?

The answer should be based only on the three provided documents.

---

## Important

**Do not simply trust the AI-generated answer.**

Check whether the original documents actually support the information provided by Gemini.

AI can help us find and organize evidence, but important information should still be verified.
